# Інформаційна вебсистема Чулаківської громади (Flask + MySQL)

Ця версія переносить зовнішнє оформлення і базові HTML-шаблони попередньої курсової на  MySQL-базу `chulakivka_portal`., якщо база вже створена. 

1. `python3 -m venv .venv`, `source .venv/bin/activate`, `pip install -r requirements.txt`.
2. Для ключа Flask виконайте `python -c "import secrets; print(secrets.token_hex(32))"` та вставте результат у `FLASK_SECRET_KEY`.
6. Запустіть `python create_admin.py` і створіть НОВИЙ обліковий запис адміністратора. Тестовий редактор із заглушкою пароля не підходить для входу.
7. `python app.py` і перейдіть на `http://127.0.0.1:5000/uk`, вхід: `/admin/login`. Логіном є email, який ви ввели на кроці 6.

- Мови узгоджено з БД: `uk`, `en`, `de`. Переклади німецького інтерфейсу поки чернеткові (успадковано частину естонських рядків) і потребують редакторської заміни; не використовувати як готову локалізацію.
- Матеріали створюються як `draft` або `review`. Публікація відбувається через наявну MySQL-процедуру `publish_publication`, після призначення ролі `admin` чи `publisher`.
- Адмінпанель дозволяє додавати/редагувати новини та сторінки, створювати події і додавати фото до наявних публікацій. Повноцінне редагування/видалення подій, відео за посиланням та зміна статусу вже опублікованих матеріалів потребують подальшого доопрацювання.
- Тіло новини зберігається у полі `body` таблиці перекладів, короткий опис формується автоматично.
- Видалення виконується через POST з CSRF-токеном. Завантаження файлів обмежене типами розширень і розміром; для публічного розгортання потрібна додаткова перевірка вмісту файлів, HTTPS та production WSGI.
